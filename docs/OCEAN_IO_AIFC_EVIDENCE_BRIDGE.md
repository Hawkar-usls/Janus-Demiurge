## GitHub Actions placement

.github/workflows/janus-ocean-io-aifc-evidence-inbox.yml runs automatically for relevant pull requests. It has contents:read and actions:read only. Offline negative tests reject changed precommit identity, changed IO source binding, fake AIFC promotion, fabricated independent observation status, hidden missing gates, and unauthorized model training.

A manual workflow_dispatch input verify_original_artifact=true can re-fetch the exact cloud artifact and compare it with the checked-in fixture while that GitHub Actions artifact remains available. A missing or expired artifact causes an explicit failure, not synthetic reconstruction. The pipeline archives an Ocean-side typed receipt; no merge/deploy action is triggered.

## Critical boundaries

- Proof-of-Observation hash integrity is not truth of the source or proof of time reversal.
- AIFC source is a draft protocol; this pipeline checks eligibility flags, not the full signed independent AIFC witness quorum.
- AIFC NOT_ADMITTED is not proof that the numerical forecast failed.
- TOPA research context is not admission as physical evidence.
- Ocean 009B's late scoring remains separate and unmodified.
- A checksum alone does not independently attest to a model's understanding or the physical origin of the data.
