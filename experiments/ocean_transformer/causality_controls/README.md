## Three separate tests

**CTRL-01 — forward causality (banana).** Forty synthetic ripening episodes of 12 steps are generated by seeded Python stdlib math. Fit a simple linear forward predictor on episodes 0–23 only. Episodes 24–31 are untouched validation holdout, and episodes 32–39 are test holdout. Predictions are written to an immutable local JSON precommit before scoring. The test expects lower MAE than maturity persistence and rejects a feature named target or other undeclared future information. This illustrates a conventional, forward-causal forecasting problem, not quantum retrocausality. No laboratory observations or independently signed forecast timestamps are included.

**CTRL-02 — QPU-005 early marginal.** Generate precisely 4096 labelled synthetic [A,C,B] rows for two cases: independent A/C and deliberately injected A/C association. Reuse the unchanged QPU-005 Fisher two-sided function with original 0.001 threshold. Confirm null does not trigger, injected association does, missing or filtered shots fail, and editing later B cannot change the primary A/C result. No Qiskit simulation or hardware job is executed. A positive synthetic injected control is not a real physical effect.

**CTRL-03 — provenance.** Verify historical JSON snapshots, JANUS QPU-005 preregistration, and checked-out original QPU protocol by actual byte-based Git blob hash. Verify the bridge cross-references point at those exact sources. Keep original and later banana annotations distinct and reject changed or mislabelled evidence.

## Reproduction

From repo root, Python 3.11; no pip dependencies.

Run unit tests:

    python -m unittest discover -v -s experiments/ocean_transformer/causality_controls -p test_controls_006.py

Generate a synthetic forecast commitment:

    python experiments/ocean_transformer/causality_controls/controls_006.py prepare --output artifacts/ctrl006_forecast_precommit.json

Score it only after writing the commitment:

    python experiments/ocean_transformer/causality_controls/controls_006.py score --input artifacts/ctrl006_forecast_precommit.json --output artifacts/ctrl006_forecast_score.json

Generate the complete report:

    python experiments/ocean_transformer/causality_controls/controls_006.py all --output artifacts/ctrl006_complete_report.json

The workflow .github/workflows/janus-ocean-causality-controls-006.yml runs these and standalone QPU/provenance controls on branch, PR, or explicit dispatch only. It has contents: read, clears provider credentials, makes zero provider calls, runs no schedule, and archives SHA-256 manifests and JSON outputs for 90 days. Outputs are single-write; do not rerun a local command over the same output path.
