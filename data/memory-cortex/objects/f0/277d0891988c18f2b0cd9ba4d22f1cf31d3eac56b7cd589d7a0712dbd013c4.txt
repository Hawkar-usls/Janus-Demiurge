OntoMS-PF

Created by https://orcid.org/0009-0001-6710-6681 Contributor https://orcid.org/0000-0002-9756-646X Licensed by https://creativecommons.org/licenses/by/4.0/ Comment This ontology extends OntoMS with concepts needed to describe phase-field simulation knowledge in a machine-interpretable way. It supports the semantic organization of physical models, numerical settings, initialization, diagnostics, and provenance to enable interpretation, comparison, and reuse across simulation workflows. Description An ontology for representing simulation input files as linked configuration records, enabling automated ingestion, provenance tracking, and semantic comparison of multiphysics simulation setups. Definition OntoMS-PF is an ontology for representing the concepts, configurations, inputs, and execution-relevant knowledge associated with phase-field simulations.
