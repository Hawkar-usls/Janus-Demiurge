Systematic Literature Review Dataset for How Supply Chain Capabilities Shape Firm-Level Strategic Positioning

This dataset contains supplementary material comprising the complete master bibliographic dataset, VOSviewer bibliometric analytical files, quality appraisal exclusion logs, and inter-rater scoring matrices. Supplementary File 1 ( studies_bibliography.csv ): Master Bibliographic Audit Dataset. Contains record-level metadata for all 95 cited master bibliography records, detailing eligibility categorisation, four-tier evidential roles, research design archetypes, indexing verification across Scopus and Web of Science, and official DOIs. Supplementary File 2 ( vosviewer_input_52_studies.csv ): Bibliometric Mapping Corpus. Contains complete bibliographic records for the 52 included synthesis studies, including author keywords, database index keywords, abstracts, and publication metadata for VOSviewer ingestion. Supplementary File 3 ( vosviewer_thesaurus.txt ): Keyword Thesaurus Mapping File. Standardised VOSviewer thesaurus mapping file detailing all keyword consolidation rules, acronym expansions, spelling harmonisations, and singular/plural merges. Supplementary File 4 ( vosviewer_keyword_frequencies.csv ): Network Keyword Frequencies. Tabulates occurrence frequencies, total link strengths, and cluster assignments for all 27 core keyword nodes in the co-occurrence network map. Supplementary File 5 ( vosviewer_cluster_membership.csv ): Thematic Cluster Taxonomy. Details cluster identifiers, colour codes, thematic focus descriptions, constituent keywords, and primary representative synthesis studies for the four network clusters. Supplementary File 6 ( quality_appraisal_78_exclusions_log.csv ): Quality Screening Exclusion Log. Complete auditable register of all 78 candidate full-text reports excluded during quality appraisal, recording failed criteria, composite scores (< 6.0), and explicit methodological rationales. Supplementary File 7 ( quality_appraisal_inter_rater_matrix.csv ): Inter-Rater Scoring Matrix. Full record of all 416 individual criterion evaluation decisions across the 52 included studies, detailing independent pre-consensus scores of Reviewer 1 and Reviewer 2, discrepancy flags, and consensus resolutions.
