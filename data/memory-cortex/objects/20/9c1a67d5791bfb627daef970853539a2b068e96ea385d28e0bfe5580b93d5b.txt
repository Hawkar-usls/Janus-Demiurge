Scabitiers: reference implementation of the scabicide exposure-verification checklist and T0–T4 outcome classification

Scabitiers is an open-source Python package that implements the eight-item exposure-verification checklist (C1–C8) and the five-tier outcome classification (T0–T4) proposed in the scabicide stewardship framework for distinguishing true scabicide resistance from pseudo-resistance in scabies treatment failure in South Asia. The rules are deterministic and conservative: a checklist item that is not recorded counts as not met, and laboratory evidence cannot move an episode out of operational failure (T2). Each result carries the reasons that produced it, and an append-only audit log keeps the full history of reclassifications. The package includes a command-line tool for CSV files, 16 unit tests and example data, and requires only Python 3.9 or later. It is intended for pharmacies, mass drug administration programmes and researchers who want to code scabies follow-up outcomes consistently or map the rules to DHIS2 or mobile e-forms. The rules have not yet been validated against patient data; the software is for research and pilot use, not for clinical decisions.
