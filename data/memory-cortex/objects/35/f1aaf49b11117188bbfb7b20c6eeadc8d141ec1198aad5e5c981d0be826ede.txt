Replication package: How Much Compiler Feedback Is Enough? A Controlled Study of Syntax References, Error Feedback, and Retrieval for Cangjie, a Low-Resource Programming Language (v1.1)

Replication package for a controlled study of multi-round compiler-feedback repair of LLM-generated code in the low-resource programming language Cangjie. It covers the initial controlled study and Original-30 validation (three models) and the expanded nine-model evaluation, evaluated on CangjieBench (HumanEval-Cangjie, ClassEval-Cangjie) and on Original-30, a new set of 30 hand-written function-level problems used as a contamination control. Contents ( cangjie_v1.1-final.zip , 2,998 files): src/ , tests/ : repair pipeline, agent baseline, retrievers, evaluation harness, statistics, cost and plotting scripts with unit tests; data/original30/ : the Original-30 problem set and its registry (authors identified by codes only); results/stage3/ , results/original30/ , results/rounds10/ : the initial controlled study (116 runs), Original-30 (59 runs) and the ten-round follow-up (9 runs), with per-task traces; results/review/ : the expanded nine-model evaluation (1,065 repair runs and 43 shared round-0 runs) with per-task JSONL traces; results/review/superseded/ keeps the three runs replaced during data consolidation (documented in the deviation record); results/stats/ : final statistics (paired permutation tests with Holm correction, bootstrap CIs, sensitivity analyses, token and list-price cost accounting); results/retrieval_eval/ , results/classifier_check/ : offline retriever selection and the blinded manual audits; docs/ : pre-specified statistical plans, the experiment deviation record and the findings checklist; earlier pilot/ablation outputs ( results/exp , ablation , reeval , repro ); for pilot and self-test runs only execution summaries are included. Reproduction : CangjieBench is not redistributed. Clone https://github.com/cjhCoder7/CangjieBench into external/CangjieBench and check out commit 68ed8f1cd96d5139a10de8da55561dcf7fd82dc3 (see README). python src/reproduce_offline.py rebuilds all statistical outputs without calling any model API; on a fresh extraction all 26 text outputs were reproduced byte-for-byte.
