Gravitational Camera: A Thought Experiment (paper, reference implementation and site)

The source of the paper "Gravitational Camera: A Thought Experiment", the Python reference implementation that produces and tests every number in it ( reference/gravcam ; the paper's Appendix B lists the module and the test for each result), the code that draws its figures, and the interactive site. The site also carries a tutorial and a book; their text is not part of this archive, so the site's tutorial pages do not build from it, while the paper, its figures and the reference implementation do. The code is under the MIT licence; the paper's text and figures are under CC BY 4.0.
