Recovering Python functions from stripped Nuitka and Cython binaries: ground truth and a measurement study (code and results)

Reproduction package for a measurement study of what static analysis recovers from stripped binaries produced by Nuitka and Cython, two compilers used to package Python programs (including malware that uses them to hinder analysis). It contains the frozen build recipes, the analysis and measurement scripts, the ground-truth construction, the canonical result tables behind every reported number, and the figure scripts, with instructions to rebuild the environment from the listed PyPI packages. No malware and no compiled binaries are included; every build is reproducible from the listed packages.
