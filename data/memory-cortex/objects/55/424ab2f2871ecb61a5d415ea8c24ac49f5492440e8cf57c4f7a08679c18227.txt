TRACE-LS West Java reference run (v1.2.0): inputs, outputs, provenance ledger, RFC 3161 time-stamp and inclusion proofs

Inputs and complete outputs of the TRACE-LS West Java run (release 1.2.0) reported in the Computers & Geosciences manuscript. part1: criterion grid, harmonised NASA GLC/UGLC events, DPMD village counts, configuration, Earth Engine script, lithology preparation script and score table, SHA-256 digests of the 27 GeoMap shapefiles. part2: all outputs, including the reporting-share estimation (outputs/westjava/effort), the known-truth experiments with seven data-generating processes (outputs/westjava/misspecified), the cross-validation designs (outputs/westjava/cv_design) and the training under positional uncertainty (outputs/westjava/positional); provenance ledger (head 9331c810002df212410045835659b4f339012bc9df26f6ac01d8f68f4d8cf034), FreeTSA RFC 3161 token (27 Nov 2026 13:25:53 UTC), PROV-JSON, per-unit and per-cell Merkle proofs, benchmarks. part3: per-cell sensitivity results. Unzip all three into one folder and run python -m trace_ls verify --ledger outputs/westjava/ledger.jsonl --base . with TRACE-LS 1.2.0 (all versions: https://doi.org/10.5281/zenodo.23226782 ) to check all 153 registered files. Sources: NASA Global Landslide Catalog; UGLC (Mancino et al., 2026, CC BY-NC 4.0); Badan Geologi GeoMap; Open Data Jawa Barat (DPMD).
