A Cost-Aware Comparison of CAE-Derived Features and Raw Pixels for Unsupervised Image Anomaly Detection

Code and complete result files for a study comparing nine image representations (raw pixels, two convolutional autoencoder activations, and PCA-compressed variants of each at 95% and 99% retained variance) under four unsupervised anomaly detectors across seven anomaly scenarios from MNIST, Fashion-MNIST, CIFAR-10 and the NIH Malaria Cell Images dataset, with a detector-free reconstruction-error baseline. Every configuration is run under three independent CAE training seeds. The archive contains the consolidated Colab notebook that produces every result, per-seed AUROC and AUPRC with stratified bootstrap intervals, a repeated-measurement timing protocol, Friedman and pairwise Wilcoxon tests with Holm correction, representation dimensionalities, CAE training costs, and a run manifest recording the software environment and file digests. Each file is documented in README.md.
