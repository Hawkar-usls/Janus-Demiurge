RationalFourReal: MATLAB software for real bases in limited-memory rational Krylov methods for matrix function actions

RationalFourReal is the MATLAB software accompanying the paper Real bases in limited-memory rational Krylov methods for matrix function actions by Tianqi Zhang and Fei Xue. It implements four methods for approximating \(f(A)b\) with a large real matrix \(A\) and a real starting vector \(b\) : restarted rational Arnoldi, truncated rational Arnoldi, rational induced dimension reduction (IDR), and the poles-and-interpolation-nodes method (PAIN). The software compares two ways of processing a pair of complex-conjugate poles: generating two real basis vectors together or taking two successive steps with a complex basis. Structured matrix-sign experiments compare the resulting approximations at common Krylov dimensions and record the work required to reach a prescribed accuracy. The reported quantities include forward errors, shifted right-hand sides, matrix factorizations, and elapsed times. The archive contains the MATLAB implementations, experiment drivers, matrix inputs, numerical results used in the paper and its supplement, and Python scripts for reproducing the figures. To repeat the main experiments, run RUN_PAPER_EXPERIMENTS from the project folder in MATLAB. The README gives commands for the additional experiments and figures.
