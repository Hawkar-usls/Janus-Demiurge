autoaihub/BioAutoML-FAST: BioAutoML-FAST v1.0.0 — manuscript benchmark release

This release preserves the BioAutoML-FAST benchmark workflow for the revised manuscript. The platform trains classification and regression models on nucleotide sequences, amino acid sequences, or tabular features. Its two-stage search first selects descriptors, then tunes the learner. Reproduce the benchmarks Clone the release with its submodules and install the locked Linux environment: git clone --branch v1.0.0 --recurse-submodules https://github.com/autoaihub/BioAutoML-FAST.git cd BioAutoML-FAST pixi install --locked pixi run sync pixi run benchmark runs the 64 datasets with five search seeds (6301–6305). pixi run ablation --n_cpu 32 compares six descriptor and learner configurations on 15 datasets (Supplementary Table S10). pixi run benchmark-pruning-off runs the 64 datasets without pruning for seed 6301. Compare these timings with the first pruning-enabled run (Supplementary Table S12). Data and trained models The model archive covers 64 datasets and five search seeds per dataset (320 fitted models). Run 1 includes the raw inputs and shared feature files. Runs 2–5 are available separately. Download the benchmark models and data from Zenodo.
