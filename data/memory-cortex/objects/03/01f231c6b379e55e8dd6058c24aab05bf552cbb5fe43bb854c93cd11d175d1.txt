Block Plugin Engine (BPE)

Overview Block Plugin Engine (BPE) is an open-source C++ software framework for the development and execution of modular robotic and real-time processing applications within the ROS 2 ecosystem. BPE addresses the need for efficient, configurable and temporally predictable execution of processing components, while reducing the coupling between algorithm implementation, data exchange, communication interfaces and execution policies. Architecture and technical contributions The framework is built around five complementary mechanisms: Plugin-based architecture: Processing algorithms are implemented as dynamically loaded software components, called blocks , enabling their independent development, configuration and reuse. Concurrent blackboard: A shared data exchange infrastructure based on wait-free, lock-free mechanisms, designed to minimise synchronisation overhead and unnecessary data copying. Fair scheduling: A scheduling mechanism for periodic processing blocks, designed to support predictable execution and the analysis of temporal behaviour. Hybrid scheduling: Integration of periodic and asynchronous event-driven execution within a common scheduling infrastructure, including explicit processing pipelines. Multi-scheduler execution: Support for multiple scheduler instances, enabling the distribution of processing workloads across execution threads. The architecture separates internal data exchange from external ROS 2 communication through configurable boundary plugins. This allows processing components to operate independently of ROS 2 communication mechanisms while retaining interoperability with the ROS 2 ecosystem. Intended applications BPE is particularly suited to applications involving: Robotic perception and sensor processing. State estimation and sensor fusion. Motion control and autonomous navigation. Periodic and event-driven processing pipelines. Embedded robotic systems with computational and temporal constraints. Experimental evaluation of scheduling strategies and execution performance. Software implementation and validation The framework is implemented in C++ and integrates with ROS 2 lifecycle management. Processing components and execution policies can be configured through YAML configuration files. The software includes examples, automated unit and integration tests, continuous integration for AMD64 and ARM64 architectures, static code analysis and code coverage reporting. This release targets ROS 2 Jazzy and Lyrical. Research context BPE has been developed at Universidad Politécnica de Madrid (UPM), within the CVAR-UPM research group, in the context of the European SHEREC project. Its development contributes to the availability of reusable software infrastructure for modular robotic systems, supporting reproducibility, software interoperability and the dissemination of research results.
