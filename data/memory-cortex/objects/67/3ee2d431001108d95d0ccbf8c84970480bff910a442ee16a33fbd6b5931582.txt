A trogocytosis-related four-gene signature stratifies prognosis and delineates immune evasion in gastric cancer and a resistance-leaning drug-response profile

Analysis code for the manuscript "A trogocytosis-related four-gene signature stratifies prognosis and delineates immune evasion and a resistance-leaning drug-response profile in gastric cancer" (Frontiers in Immunology, manuscript ID 2035159). The deposit contains the scripts used to score a 23-gene trogocytosis programme in TCGA pan-cancer and TCGA-STAD data, to derive and validate the four-gene signature (GULP1, CDH2, CTLA4, NRP1), and to perform the immune, drug-sensitivity, single-cell and virtual-knockout analyses reported in the paper. The 23-gene trogocytosis set was adopted unchanged from Liu et al., Int Immunopharmacol 2026;187:117273 (Supplementary Table 1); it was not curated by the present authors. The gene list is reproduced in `gene_set/` and the provenance is stated in the README and in Table S1 of the manuscript. All input data are public (TCGA via UCSC Xena, GEO, GDSC2, RCSB PDB). No individual-level data are included.
