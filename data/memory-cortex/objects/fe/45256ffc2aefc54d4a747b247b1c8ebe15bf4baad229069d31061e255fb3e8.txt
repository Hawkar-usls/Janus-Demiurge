Data and analysis code for "From Fragmented Ergonomic Guidance to Design Defaults: A Design-Support System for XR Interface Layout"

Supporting data and analysis code for the manuscript "From Fragmented Ergonomic Guidance to Design Defaults: A Design-Support System for XR Interface Layout," submitted to the International Journal of Human-Computer Interaction. Twenty-four designers each completed a VR UI layout task under two conditions: a baseline handoff workflow and an XED-supported workflow. This deposit includes derived layout measurements, process and questionnaire data, SUS item responses, communication event logs, literature search records, and analysis scripts. Participants' original design artefacts and interview recordings are not included. For details on the dataset, file structure, and analysis procedures, see README.md.
