Reproducibility Data and Code for Certificate-Based Set-Membership Testing of Additive Host–Guest Competition

This repository contains the computational reproducibility package accompanying a study of additive host–guest competition under mismatched chemical conditions. It includes synthetic benchmark data, Python implementations, rational infeasibility certificates, independent certificate-verification routines, and documented numerical comparison results. The primary 500-case benchmark and the 24-case structural comparison can be reproduced using the supplied scripts. Additional sensitivity and held-out results are retained as archived summaries because complete case-level inputs are not available in this release.
