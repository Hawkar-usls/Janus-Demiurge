Artifact: A Memory Note Can Change What a Formal Proof Checks: Experiments With an LLM Verification Agent on OpenTitan

Everything behind the paper "A Memory Note Can Change What a Formal Proof Checks: Experiments with an LLM Verification Agent on OpenTitan" (M. Ghonim and X. Song) except the prover and the models: the registered protocols with their SHA-256 hashes; the decision log; for every campaign, the harness, prompts, plans, stores, trial order, dispatch state and analysis; one directory per trial with the executed run.tcl , parsed verdicts, licence receipt, property and assumption files, the store written back and a transcript summary; the agent-free controls, mutation-gate reports and formal-coverage runs; and every generator with the tables and macro files it writes. One command regenerates every number in the paper without an EDA licence ( rm paper/manuscript/tables/*; bash paper/finalize.sh ; Python 3.9+ with numpy and matplotlib). The manuscript itself is not included. Raw JasperGold logs and consoles are not included; the parsed verdicts and the executed Tcl are. Full trial transcripts are summarised, home-directory paths are replaced by <home>/ , and journal names in the decision log are masked. Re-running the trials needs JasperGold 2026.06, OpenTitan at the commit given in the protocols, and access to the named models. Built from commit <commit> by paper/package_artifact.py ; MANIFEST.txt lists every file and memory-study-artifact.sha256 gives the archive's checksum.
