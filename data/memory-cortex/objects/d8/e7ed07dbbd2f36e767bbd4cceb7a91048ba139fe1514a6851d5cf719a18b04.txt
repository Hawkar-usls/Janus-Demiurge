NP-1 CRE: Descriptive Membrane-Fluorescence Analysis and Reproducibility Code

This software package contains revision-stage Python code supporting the descriptive analysis and numerical reproducibility of the manuscript entitled “Multidimensional Profiling of Heterogeneous NP-1-Associated Membrane Responses among Nine Clinical Carbapenem-Resistant Enterobacterales Isolates.” The computational workflow includes endpoint data reconstruction, technical-replicate statistics, z-score standardization, kinetic data reconstruction, missing-value handling, and numerical validation. The package operates on previously normalized supplementary datasets. Execution instructions, software dependencies, and validation records are provided to facilitate computational reproducibility and transparency.
