Data for: General-purpose LLMs outperform single-cell language models at cell type annotation when expected types are known

Data for the paper "General-purpose LLMs outperform single-cell language models at cell type annotation when expected types are known". Test sets: the preprocessed, stratified test sets of 1,000 and 10,000 cells of the four datasets HFRA, HIHA, Zeisel and human pancreas (*_sub1000_stratified.h5ad, *_sub10000_stratified.h5ad), on which the methods are scored. Clustering samples: about 100,000 cells per dataset and all 11,704 cells of human pancreas (*_context.h5ad), used by the methods that annotate clusters. Additional analyses: additional_analyses_data.zip holds the predictions, the model answers, the clusters, the request log and the mapping rows of the prompt-context ablation and the imperfect-list analysis. additional_analyses_README.md describes its contents and how to score the analyses again with the code of the repository. Zeisel source file: Zeisel_l5_all_rev1.h5ad holds the mouse nervous system data of Zeisel et al. (2018), the authors' file l5_all_rev1.loom from mousebrain.org (downloaded on 19 December 2025), converted to h5ad with scanpy. Cells are named by CellID and genes by their symbol, with Ensembl IDs in var['ensembl_id']; the raw counts are unchanged in X and layers['counts']. The pipeline builds the Zeisel test sets and clustering sample from this file. Please cite Zeisel et al., Molecular Architecture of the Mouse Nervous System, Cell 174, 999–1014 (2018), doi:10.1016/j.cell.2018.06.021, when using it.
