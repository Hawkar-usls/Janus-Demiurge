GenomeInfer 1.0.0-review: source code, release database and verification outputs

GenomeInfer is a native macOS application for Apple silicon that reads a checksummed release database built from public macroalgal genome annotations and calls a Python and Snakemake engine for a local read-to-variant pipeline. The engine keeps ten evidence classes and five absence states apart, so no annotation is presented as a measured compound. This record contains the materials behind the article "GenomeInfer: a provenance-tracking macOS workbench for evidence-graded annotation and read-to-variant analysis of public macroalgal genomes", submitted to BMC Bioinformatics: the source of the application (public release commit ee0e674) and of the engine (public release commit 7a5ed41); the release database release_8eb541351af379c8c57998634826c61f (SHA-256 30652b3d6ad5a3621b5815deb9ab84a260d8b9e6b616d9a16bd328077823318d) with its build summary; the outputs of a public read-to-variant run (ENA run ERR12682753 against assembly GCA_964200175.2) made on 26 November 2026 at engine commit 23e4197, the parent of 7a5ed41, which has the same read pipeline code; the logs of the application and engine test runs on the public release commits from the same day; and the scripts that draw the article figures. The README lists every file and gives the steps to check checksums and repeat the analyses. Licences: the source code is released under the MIT License (LICENSE-CODE.txt).
