REAP: Reproducible Embeddings via Averaged Projection

Second pre-release of REAP. It adds the pieces for checking REAP on held-out documents, choosing K and map settings with every choice declared, and placing new passages into an existing map. Install from this tag (REAP isn't on PyPI yet): pip install "reap-topics[projection] @ git+https://github.com/Thru-Echoes/REAP@v0.2.0" New reap.holdout : hold-out comparison harness, with parametric UMAP and identity baselines. reap.selection : choose K and UMAP settings with every choice declared and no defaults. reap.placement : four projection heads (REAP's MLP, a scaled MLP, ridge, nearest-neighbour), held-out placement of reference passages, and a calibrated inside test. Versioned result record files ( reap.repro_bundle ). Snapshots for the earnings-call and presidential-speech corpus, and raw Korean-forest pledge embeddings. Drivers for hold-out cells and their fail-closed aggregation, and a driver that maps a reference set and projects other document sets into it. Parameter-search records: the benchmark and reference drivers refuse to run without one, so default settings can't be mistaken for results. Fixed train_projection_head no longer stops when the training rows leave a last batch of one row. The README and CONTRIBUTING install and clone commands now work. Full list in CHANGELOG.md .
