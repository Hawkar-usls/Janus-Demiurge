A Systematic Review of Software Update Supply Chain Security: Attacks, Verification, and Defence Mechanisms

Abstract - Software update supply chains face escalating threats that compromise software integrity and expose downstream systems to widespread exploitation. This study presents a systematic literature review of software update supply chain security across development, building, signing, distribution, verification, and installation. Relevant studies and technical standards were retrieved across academic databases and screened using structured eligibility criteria. The review evaluates supply chain attack vectors alongside cryptographic hashing, digital signatures, Public Key Infrastructure (PKI), software provenance, Software Bills of Materials (SBOMs), The Update Framework (TUF), Supply-chain Levels for Software Artifacts (SLSA), and the NIST Secure Software Development Framework (SSDF). Synthesising the selected literature demonstrates that while cryptographic checks authenticate binaries and provenance frameworks harden build pipelines, standalone controls offer partial protection and leave residual lifecycle vulnerabilities. Accordingly, a lifecycle-based security coverage analysis is proposed to map stage-specific attack vectors against existing controls, exposing protection gaps and guiding future research toward resilient, end-to-end software update architectures.
