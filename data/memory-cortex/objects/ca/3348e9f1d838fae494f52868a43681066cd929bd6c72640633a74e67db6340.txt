Replication package for "How flood forecast revisions affect substation protection and expected load shed"

This replication package reconstructs the numerical results in “How flood forecast revisions affect substation protection and expected load shed.” The analysis measures how far flood-scenario probabilities must move before another substation protection plan becomes preferable, and how much expected operating loss can be avoided by changing plans. The Imelda study enumerates feasible deployments. The Harvey study evaluates archived alternatives and reviews full-investment solutions at selected, fixed forecasts. The archive contains the model inputs, Python scripts, reference CSV files, plotting routines, scenario weights, archived solver records and a replication guide. The default workflow runs offline after dependency installation, uses SciPy/HiGHS to recompute dispatch, checks the published values in Tables 1–4, and regenerates Figures 1–4. Eight archived Gurobi runs support the Harvey fixed-forecast results. A separate optional driver can launch new full-space searches with a suitable Gurobi license.
