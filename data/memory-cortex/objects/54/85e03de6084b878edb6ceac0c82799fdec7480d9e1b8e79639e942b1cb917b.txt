SurtGIS: a high-performance raster geospatial analysis library, CLI and dynamic tile server in Rust

High-performance geospatial analysis library, CLI and dynamic tile server in Rust: 127 algorithms (56 also available in the browser via WebAssembly), streaming I/O for arbitrarily large DEMs, native CRS reprojection, windowed GeoTIFF and Cloud Optimized GeoTIFF reads (including ZSTD, band-interleaved, bottom-up and BigTIFF files such as the AlphaEarth Foundations embedding tiles), a native ECW decoder, an end-to-end satellite composite pipeline, foundation-model embeddings as first-class rasters (similarity maps, PCA false colour), embedded verifiable provenance in every output with a bit-exact determinism contract, and SurtGIS Server (`surtgis serve`), an analysis-first XYZ tile server with materialisation jobs where terrain operators, spectral formulas and embedding operators are tile-URL parameters. Covers terrain analysis, hydrology and remote sensing from a single dependency-free binary. This record archives the source of release v1.9.0.
