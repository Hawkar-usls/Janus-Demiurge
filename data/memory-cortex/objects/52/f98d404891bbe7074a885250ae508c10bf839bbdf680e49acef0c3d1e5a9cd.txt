Shall-We-Dance/ONT-LibQC: ONT-LibQC v1.2.0

This release adds a combined Micro-C QC report and a local beta workflow for shallow single-cell RNA libraries. Compare fragment sizes, Pairtools categories, ligation structure and inferred MNase fragment sizes across sublibraries. The report includes separate genomic block and insert-length figures, a downloadable SVG overview and expandable per-library detail. Micro-C example Follow each sublibrary across plots with a consistent, brighter palette. Reference species have their own fixed colors. Chromatin size and genomic profiles now have their own report card. Chromatin example Run shallow single-cell RNA QC locally for supported 10x Chromium, MGI C4 and Parse Evercode layouts. Reports summarize barcode evidence, cDNA yield and observed gene-assigned molecules. scRNA QC guide Portal operators can configure a lower memory reservation for preparation and reporting. The worker reserves additional memory for alignment and releases it when that phase finishes. Full changelog
