sparql-generate/vscode-sparql-generate: v0.2.0

For SPARQL-Generate 2.6.0. Highlighting of RAISE(message, value, ...) , in any case, as a built-in call (highlight-sparql-generate 0.2.0). Snippets raise ( RAISE("message", ?value) ) and bind-raise ( BIND(COALESCE(expr, RAISE(...)) AS ?var) ). A run stopped by a RAISE shows its message and values, in the notification ( RAISE, line 11: Not allowed — "bob" , Go to RAISE ), in a diagnostic at the RAISE call, and in the log. Another failure of the Java engine shows the error the engine reported ( Document not found: <…> ), not only the exit status. Settings sparqlGenerate.graphsToFiles ( --graphs-to-files ) and sparqlGenerate.targets ( --targets , a JSON file relative to the query): the named graphs that name RDF files are written to these files. With an engine older than 2.6.0, the run is refused with a message that offers to download the latest release. The Python backend does not take them. With sparqlGenerate.java.engineVersion = latest , an engine downloaded before 2.6.0 prompts once (per version) to download the latest release, without holding the run. Download the Java Engine takes a version as argument.
