Executable Representations for Cumulative Discovery: A Closed-Loop Benchmark for Frozen Language Models

An agent that invents a useful representation should be able to use it to investigate a later phenomenon. We introduce COMPDISC, a sequential four-stage integer-cascade benchmark in which a frozen language model authors executable distinctions and laws, selects measurements that test its competing predictions, and carries the resulting program into the next stage. In the locked v4 evaluation on a frozen 27B Qwen service ( qwen38-27b-frozen ; 263 audited calls), the model completed all four stages on all three mechanisms (CD31, CD32, CD33), scoring 32/32 and 48/48 on the first two held-out panels of each mechanism. Across nine Stage-3 pairs with three measurements per arm, adaptive inquiry achieved 485/576 (84.20%) versus 436/576 (75.69%) for uniform random querying (+8.51 percentage points; 5 wins, 3 ties, 1 loss), using 70 versus 19 Stage-3 model calls. Holding the fitted Stage-3 law fixed and substituting either earlier representation reduced accuracy by 75.39 and 72.66 percentage points across the eight retained trajectories with an adopted law. All 29 admitted initial hypotheses conflicted with accumulated observations (0/29 surviving); seven trajectories deployed a law generated during mid-probe refresh and one synthesized an exact fitting law at final commitment (64/64). This v1 release includes the preprint PDF and a sanitized, portable zero-model-call offline verification archive ( compdisc_v4_verification_bundle.zip ) containing the frozen harness code, task specifications, all 263 request/response receipts, and standalone verifier ( verify_release_offline.py ).
