author-merge-risk-control

Code, locked configuration and aggregate results for evaluating confidence thresholds that decide which author records a disambiguation model merges automatically, on seven S2AND sources (766,133 records in 27,658 name blocks) and the external OC-AND benchmark (227 labelled names, 61,971 records). What the pipeline does Splits the name blocks of each S2AND source at random into training, validation and pool blocks. Computes S2AND pair features under six metadata conditions, fits pairwise models (all sources; leave one source out; with and without random field masking) and scores every pool block; clusters records within blocks and calibrates the pairwise probabilities. Derives a record-level confidence for automatic merging and evaluates an empirical threshold, a stratified threshold and a certified threshold (Learn-then-Test with a Hoeffding–Bentkus test) within sources over random calibration/test splits. Applies thresholds chosen on other sources to a held-out source and to OC-AND, which it converts from its published files. Evaluates certified procedures with labelled blocks of the target source, a known-threshold reference, pooled, proportional and source-balanced calibration, other confidence signals, and the author profiles that automatic merging builds. Data produced results/g0/ : data summary, reproduction of published B3 F1, signal and masking-rate selection, test power. results/g1/ : within-source summary over random splits; decisions on the pre-specified criteria. results/g2/ , results/g2x/ : transfer to held-out sources, local recalibration, known-threshold reference, source-balanced calibration. results/rev/ , results/rev2/ : procedures at equal labelling budgets, profile measures, proportional calibration, confidence signals, whole-target curves, profiles under locally certified thresholds, calibration blocks crossed with start weighting. results/s1/ , results/s2/ : model metadata; distance cut-offs and calibration per model and condition; B3 on OC-AND. data/ : checksums of the input files; counts of the converted OC-AND. All result files are aggregates; no file lists records, names or authors. The S2AND and OC-AND files are not included.
