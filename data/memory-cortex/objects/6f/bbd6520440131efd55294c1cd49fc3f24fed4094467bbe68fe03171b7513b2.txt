ContextLab/htfa: HTFA 0.2.0

HTFA 0.2.0 0.2.0 adds options to the BrainNet Viewer-style network plots and animations in htfa.brainnet ( #188 , #189 , #191 ). A call that passes none of the new arguments takes the 0.1.0 code path. Install pip install "htfa[plot,brain3d]==0.2.0" Python 3.10 or newer. Network plots and animations Per-node colors. node_color accepts one color per node in plot_network and animate_network , and per-frame colors of shape (T, K) in animate_network . Per-frame node sizes. animate_network accepts sizes of shape (T, K); radii are scaled jointly over all frames. connectivity=None draws no edges when sizes or colors carry the time axis. Several views per frame. views draws views side by side with one shared crop; frame_size sets the exact output size. Legend. legend adds rows of colored dots and lines with labels under the views. Caption on stills. plot_network accepts caption , one line of text drawn by the same code that draws a frame caption in animate_network . Reserved legend rows. An empty legend row ( legend=[[], row] ) reserves a blank band of the normal row height. Custom layouts. compose(images, t) on animate_network builds each frame from the per-view images. Parallel rendering. n_jobs draws frames in worker processes; a blank render or a dead worker restarts the pool, up to 5 times. Measured on 300 frames at 1920x1080 with two views (Apple Silicon): 61, 50, 35 and 31 s with 1, 2, 3 and 4 workers. Workers take about 4 s to start, so short movies do not gain. Encoding. crf and faststart in animate_network and htfa.brainnet.write_animation ; preset passes an x264 preset name ( "ultrafast" to "placebo" ). With crf=None and preset=None the encoding is as in 0.1.0. Helpers. htfa.content_box returns the bounding box of the non-background content of one or more images; the style key supersample sets the anti-aliasing multiple (default 2). Fixes macOS memory. Closed render windows are released (VTK 9.5 and later). In 0.1.0 each render kept its window in memory, 5 to 9 MB per render with the ch2 mesh. Mesa 26 (Ubuntu 26.04). Edges and per-node colors are stored per point instead of per cell; with Mesa 26's software renderer 0.1.0 drew no edges. Documentation build The gallery example plot_2d_image_factors.py fits K=6 and K=80; tutorial 05 shows the K=320 fit ( #190 ). Known limits With edges drawn over the translucent mesh, renders vary by a few dozen pixels from run to run (VTK depth peeling); this was also the case in 0.1.0.
