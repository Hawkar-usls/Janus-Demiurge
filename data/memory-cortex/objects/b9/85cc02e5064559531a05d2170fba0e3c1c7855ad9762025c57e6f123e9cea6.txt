D-I-TASSER-X template library (threading / LOMETS3 templates and sequence profiles) Snapshot of the I-TASSER/LOMETS3 template library used by D-I-TASSER-X (https://zhanggroup.org/D-I-TASSER-X/), the version used for the benchmark of the D-I-TASSER-X paper. One zstd-compressed tar archive per library directory; each archive unpacks to a directory of the same name inside the D-I-TASSER-X library directory (ITLIB): PDB template structures MTX, SIG, DEP, CNT, dotProfiles, summary, stride template profiles / features used by the threading programs CE CEthreader template library Bfactor template B-factors (ResQ) nr non-redundant sequence database (PSI-BLAST, input stage) Unpack (zstd >= 1.4): cd ITLIB && for f in /path/to/*.tar.zst; do zstd -d --long=27 -c "$f" | tar -x; done Check: md5sum -c MD5SUMS
